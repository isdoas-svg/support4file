  • 검사명: 검사 약어로 작성 가능합니다. (단, Holland는 제외 / 예: MLST, MAJOR, CST-A)
  • 검사지 작성 시: 검사명 + 학교급 + 언어 + 검사지
    ※ 청소년(중/고 통합)도 반드시 학교급(중등용/고등용) 입력 필수, '한국어' 표기 필수
    ex) MLST 초등용 한국어 검사지, GOLDEN 중등용 영어 검사지

    ex) NEO 중등용 결과지, WISE 고등용 교사용 통계표
  • 해석지침서 / 엑셀자료: 학교급 구분 없이 입력
    ex) KCMII 엑셀자료, CACV 해석지침서
